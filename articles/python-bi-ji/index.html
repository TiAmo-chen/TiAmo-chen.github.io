isinstance VS type

isinstance 和 type 的区别在于：

-   type()不会认为子类是一种父类类型。
		`type(A()) == A`
-   isinstance()会认为子类是一种父类类型。
		`isinstance(A(), A)`

装饰器decorator

def dec(f):
	pass

@dec
def double(x):
	return x * 2

decorator含义就是将下面的函数作为参数传递给@后面的函数
